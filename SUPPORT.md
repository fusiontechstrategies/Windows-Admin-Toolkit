# Support

## Questions and troubleshooting

Use GitHub Issues for reproducible bugs, documentation problems, and focused feature requests.

Before opening an issue:

1. Read [README.md](README.md) and [TESTING.md](TESTING.md).
2. Run the toolkit with the same PowerShell edition named in the issue.
3. Confirm the target is authorized and that required connectivity already exists.
4. Remove all credentials, tokens, real hostnames, private address inventories, and confidential output.

Include:

- Windows edition and build
- PowerShell edition and full version
- Toolkit version
- Local, WinRM, or PsExec mode
- The selected workflow
- Exact error text with sensitive details removed
- Minimal steps that reproduce the behavior

## Security reports

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).

## Scope

Community support is best effort. The project does not provide emergency production support, Windows licensing support, network remediation, or help bypassing organizational security controls.
